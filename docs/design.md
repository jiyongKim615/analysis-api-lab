# 설계와 API 계약

## 입력과 데이터

`fixtures/vocs.json`에는 중복, 짧은 문장, 무관한 문장, 여러 감정, 판단하기 어려운 문장을 포함한 합성 피드백 11건이 있습니다. `aspect_catalog.json`은 합성 측면 분류표, `reference_context.json`은 예제 단어 목록입니다. 전화번호 모양의 `010-0000-0000`과 `example.com` 주소는 마스킹 확인용 문자열입니다.

`AnalysisRequest`는 직접 전달한 `vocs` 또는 저장소의 페이지·조건 조회를 받습니다. 두 방식을 섞거나 페이지 크기를 넘는 inline 입력을 보내면 거부하며 조용히 잘라내지 않습니다. 기본 키는 `(source_system, voc_id)`입니다. 설문용 복합 키를 사용하면 `dataset_id`, `recorded_on`, `survey_id`, `response_id`, `question_id`를 모두 제공해야 합니다.

JSON 저장소와 읽기 전용 SQLite 저장소는 같은 인터페이스를 따릅니다. 중복 검사는 조회 스냅샷 범위에서 수행하며, SQLite는 제한된 이름의 쿼리와 바인딩 변수를 사용합니다. 스냅샷은 최대 50,000건으로 제한합니다. 실시간 분산 데이터 적재는 구현하지 않습니다.

## 요청별 실행

`api.py`와 `cli.py`가 같은 `AnalysisPipeline`을 사용합니다. 단계별 component는 요청 안에서 생성합니다. 외부 응답은 DTO 검증 후 원문 포함 여부·분류 코드 유효성을 검사합니다. 유효하지 않은 결과를 중립 감정이나 성공으로 바꾸지 않습니다.

provider gateway는 제한된 동시 호출, 시간 제한, 실패 항목만의 재시도를 담당합니다. 부분 성공의 유효한 항목은 유지하고 거부한 코드도 남깁니다. 사유 추출은 기본적으로 불만 분류에만 적용하며 `negative_emotion` 정책으로 바꿔 비교할 수 있습니다. 요약은 발췌 방식입니다.

`offer`의 공개 여부 값은 실습용 규칙 계산 결과이며 실제 접근 권한을 부여하지 않습니다. 항상 검토가 필요하다는 상태를 유지합니다.

## HTTP 계약

| 경로 | 동작 |
| --- | --- |
| `GET /health` | provider 종류와 지원 요청 종류 |
| `POST /run_agent` | 전체 결과 또는 간략 결과, `isStream`으로 JSON/SSE 선택 |
| `GET /runs/{run_id}` | 같은 실행 주체의 저장 결과 조회 |

`422`는 잘못된 입력, `501`은 지원 범위 밖의 요청 종류입니다. 오류 응답에는 입력 원문을 반사하지 않습니다. 요청 본문은 최대 2 MB로 제한합니다.

SSE는 `START`, 단계별 `STAGE`, 결과 `CHUNK`, 종료 `DONE` 순서입니다. 처리 실패는 `ERROR`와 `DONE.success=false`로 전달합니다. 클라이언트 연결 종료 시 provider 작업을 취소하고 완료되지 않은 결과는 성공 파일로 저장하지 않습니다. 단계별 실패가 있어도 요청 자체가 완료되면 `DONE.success=true`일 수 있습니다.

## 저장과 실행 주체

결과는 `output/runs` 아래 실행 주체별 해시 경로에 저장합니다. 검증한 서버 토큰으로 실행 주체를 정하며 요청 본문의 사용자 ID를 신뢰하지 않습니다. 토큰이 없으면 loopback 요청만 허용합니다. 토큰은 이 예제의 단일 서버 credential로, 다중 사용자 계정 시스템이 아닙니다.

실행 ID가 같고 내용도 같으면 재저장할 수 있고, 다른 내용이면 충돌로 거부합니다. 파일은 원자적으로 발행하며 권한은 `0600`입니다. 자동 보존 기한·삭제 작업이나 분산 저장소는 포함하지 않습니다. CLI CSV는 수식 시작 문자를 이스케이프합니다.

## provider 범위

기본 offline provider는 고정 키워드와 규칙으로 동작합니다. 문장의 의미를 폭넓게 이해하는 모델이 아니며, NLP 정확도 평가에 사용할 수 없습니다.

선택적인 `JsonHttpProvider`는 provider 프로토콜을 실습하는 어댑터입니다. `CX_PROVIDER=http`, `CX_ALLOW_EXTERNAL=true`, HTTPS endpoint, 허용 host 설정이 필요합니다. 인증이 필요한 endpoint의 토큰은 서버 환경에서만 읽습니다. TLS 검증을 유지하고 redirect·환경 proxy를 사용하지 않으며 응답 크기를 제한합니다. 연결 동작은 MockTransport로 검증했고 실제 서비스와 연결하지 않았습니다. 기본 CLI demo는 환경의 provider 선택과 무관하게 offline으로 실행합니다.

정규식 마스킹은 전화번호·이메일 등 제한된 패턴만 처리합니다. 완전한 익명화나 규정 준수를 제공하지 않습니다. 합성 데이터로만 실습합니다.
